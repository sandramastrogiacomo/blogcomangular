# Blog de Repórter a Dev 💻💖

Este é um projeto de blog desenvolvido com Angular, criado para documentar e compartilhar minha jornada de transição de carreira de repórter para desenvolvedora. O blog traz reflexões, dicas, desafios e aprendizados no processo de mudança de profissão, além de ser um espaço para compartilhar o que estou aprendendo como desenvolvedora. 🚀

## 🎯 Tecnologias Usadas

- **Angular**: Framework JavaScript utilizado para a construção da aplicação. 🔧
- **HTML5 & CSS3**: Para a estruturação e estilização da interface. 🎨
- **TypeScript**: Linguagem principal utilizada no desenvolvimento do código-fonte do Angular. 📝
- **Bootstrap** (se aplicável): Para criar um layout responsivo e estilizado. 📱

## 🔥 Funcionalidades

- **Postagens de Blog**: Exibe artigos sobre minha jornada de transição de carreira, dicas para quem está começando no desenvolvimento e reflexões pessoais. ✍️
- **Detalhes de Postagem**: Cada post pode ser acessado em sua totalidade ao clicar no título. 📖
- **Responsividade**: O blog é totalmente responsivo, adaptando-se bem a dispositivos móveis e desktops. 📲
- **Design Limpo e Intuitivo**: Foco em uma navegação simples e clara, com layout que facilita a leitura e a exploração do conteúdo. 💡

- **Angular CLI**: O Angular CLI é necessário para rodar o projeto. Para instalá-lo globalmente, execute o comando abaixo:

💬 Sobre o Projeto
Este blog é parte da minha jornada de transição de carreira de repórter para desenvolvedora de software. A ideia surgiu da vontade de documentar o processo, refletir sobre os desafios e compartilhar tudo o que aprendi ao longo do caminho. Através deste blog, espero inspirar outros que estejam considerando a mudança para a área de tecnologia, oferecendo dicas práticas e recursos úteis. 💡✨

Este projeto faz parte do Desafio do Bootcamp Decola Tech 2025 da DIO, em parceria com a Avanade. Estou muito empolgada com esse desafio e com as oportunidades de crescimento que ele proporciona! 🎓🌟
